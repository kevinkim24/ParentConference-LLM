# ParentConference-LLM
LLM interaction for new student-teachers to practice speaking with students' families.

The base_url OpenAI client variable must be set to the LM Studio base url. As is, it is set to http://localhost:1234/v1.
The local model is currently set as "google/gemma-4-e4b".

The FLASK_URL variable must also be set in chat.html, to be consistent with the port set in Flask.
